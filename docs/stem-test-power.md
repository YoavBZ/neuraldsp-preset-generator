# The deciding song-level test: power, before anything runs (2026-10-13)

The [set-5 plan's amendment](set5-test-plan.md) declared that the product question would be
decided by a combined set-5 + MedleyDB test from separated stems. That test would compare C′'s
pick with `generate`'s shipped start on crunch, with power computed first. If crunch power came
out below about 60%, the plan said so would be stated, and the test would become the last check
before roadmap step 9: closing the chooser for the product.

## What data exists

- **MedleyDB (set 6) gives no usable parts.** No DI-role rule passes on development data
  ([declaration](validation-set6.md)).
- **Set 5's crunch parts with a mix span 3 bands:** BKS (with Fytakyte merged in), Saturn
  Syndicate and Ronnie Jones. The Ferryboat Men has no mix, because its re-hosted tracks
  don't share a timeline.

## Power

- **The spread:** from set 5's band-to-band spread on the amp-track run, C′ against the start
  on crunch (report-only, already published), the SD of band means is 0.101.
- **The bar:** "helps" needs the 90% upper bound below 0. The table shows the power to get
  there:

  | crunch bands | half-width | power at −0.05 | power at −0.10 |
  |---|---|---|---|
  | **3 (what exists)** | **0.170** | **9%** | **18%** |
  | 4 | 0.119 | 13% | 37% |
  | 8 | 0.068 | 32% | 80% |
  | 12 | 0.052 | 47% | 94% |
  | 20 | 0.039 | 68% | 99% |

- **The expected effect:** development's C′ against the start on crunch was −0.0985, so −0.05 if
  halved. On set 5's amp tracks it was −0.023.

## Consequence (proposed; the user decides)

- **The test can't decide:** about 9–18% power, far below 60%. Running it would spend set 5's
  second use on an outcome that can't change the decision.
- **By the declared rule, the chooser closes for the product** (step 9). C′ stays the research
  network.
- **Reopening needs 8–12 new crunch bands with a DI.** No public source has them: Cambridge is
  exhausted for us, MedleyDB has no usable DIs, and everything else is paid or rendered. The
  remaining route is recording players directly, a DI plus a mic'd amp, one band per player.
- **Set 5 stays held out,** for that later test.
