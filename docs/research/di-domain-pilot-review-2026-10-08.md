## Required corrections

1. **Calibration separation is currently overstated.** `P2-downloads/_tools/catalog_p2.py:89–140` estimates full-file/window lags and selects candidates using whole-crop activity/clipping. `cut_crops_p2.py:61–77` rejects candidates using GCC-PHAT over all ten seconds; `:90–103` saves full-crop alignment/QC. Thus seconds 4–10 already influenced selection and recorded offsets. Keeping these development crops is reasonable, but disclose that dependence. Estimate operative per-take lag/polarity from seconds 0–4 using a frozen method; use inherited lags only as provenance, not a fallback that rescues failed calibration. Freeze rejection rules, lag bounds, ambiguity thresholds, and handling of missing/invalid takes before execution; reduced denominators must not silently pass the 9/12 gate.

2. **Specify timing coordinates and isolate processing across the split.** `learn/direc_check.py:36–37` documents a Morgan render offset of 52 samples; training reads rendered wet against unshifted DI (`direc.py:68–72`). This makes blindly aligning native wet to DI before neural inference unsafe: the network may already compensate the training offset. Declare the native/Morgan input coordinates and output comparison coordinates, with any arm-specific fixed correction derived only from calibration. No delay/polarity optimization on scored predictions. Six-second target FFT EQ must use only seconds 4–10, matching training; fitting the FIR on a ten-second FFT-EQ'd target would import score audio into calibration. Define FIR support, boundary trimming, and inference context so calibration cannot consume scored samples through centered/noncausal processing.

3. **Remove scoring-DI EQ from the FIR prediction.** The proposal explicitly canonicalizes FIR output with the target's scoring EQ. That curve depends on the held-out DI spectrum (`direc.py:241–249`), so the evaluated FIR benefits from score-label information despite fitting its taps on seconds 0–4. Calling it oracle-assisted does not make it an independent recoverability gate. Minimal fix: fit/evaluate the FIR against raw DI, with all fitted gains/filters derived from calibration; keep that raw-pair diagnostic separate from the neural canonical-target benchmark. Alternatively freeze a calibration-only canonicalization for this control. Scored DI may construct the neural benchmark target; it must not modify any competitor's prediction.

4. **A failed 256-tap inverse is inconclusive.** At 48 kHz it spans only 5.33 ms. A causal inverse can fail on mic/cab phase, room tails, spectral nulls, noise, or calibration frequency coverage even when useful recovery is possible. The proposed ridge value does not resolve those limitations; tap origin, convolution direction, intercept/DC handling, and finite-output rules are also unspecified. Freeze those details and retain the inexpensive control, but interpret success as evidence of limited recoverability and failure as an inconclusive control. Improvement over wet alone can reflect EQ correction; report flatref alongside it. Do not infer irrecoverability or neural domain shift from FIR failure.

5. **Freeze an executable scoring definition and separate outcomes.** Full-band log-magnitude loss can emphasize noise/lost bandwidth; the catalog's claimed roll-off above 4 kHz is a reason for a declared band-limited diagnostic, not established truth. Define that diagnostic's exact STFT-bin masks, floors, and standardization order. State that MR-STFT alone differs from training's waveform-plus-spectral objective. Center-three-second scoring matches validation's target crop, but six-second inference does not match its input context (`direc.py:265–271,356–385`); choose one inference procedure and label it accurately. Define aggregation explicitly, e.g. median of per-take reductions `1 − Lnet/min(Lwet,Lflat)`, exact ties, group criteria, near-zero denominators, and nonfinite outputs. Report all individual arms and losses; keep waveform L1 diagnostic under frozen alignment. A self-comparison only checks metric plumbing; route the oracle through the actual target-processing path. Distinguish **screen pass**, **native failure with passing controls**, and **inconclusive due to QC/control failure**. One Morgan preset supports only that synthetic condition. Neither the arbitrary 10% thresholds nor 12 correlated takes establish significance, broad domain transfer, or authorization for more training.
