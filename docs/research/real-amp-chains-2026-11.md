# Only captures reach 100 real amp chains

*Research, 2026-11-01, for the ML session; not a declared plan. Public pages only: nothing was downloaded, no account was made and no terms were accepted.*

No open dataset holds 100 real amp chains with a matched DI. Purpose-built DI-plus-real-amp datasets add up to about **13 physical amps**, and only **3 have a mic on the amp** (Guitar-TECHS, already in the project, one of them held out). Band multitracks with mic'd amps are nearly all in use or held out. The only open source with **thousands of distinct chains** is Neural Amp Modeler (NAM) captures on TONE3000. A capture models one amp at one fixed setting; it is not a recording. Only `amp-cab` packs **can** be real mic'd chains, and the tag is the creator's: some use a built-in or free cab IR, so the packs need filtering to those whose description names a mic. Running the project's own DIs through such a capture gives exactly matched pairs. Each pack's licence appears to fit, but TONE3000's terms forbid bulk download, so the clean route is to ask TONE3000 for research access, which is the user's call. GOAT, already requested, renders real DIs through captures drawn from a 7,000-profile pool, each joined to a random Nolly cab IR, so no render is one real rig. Its "8.5 TB" is a download statistic, not its size. For every capture route the main catch is input level, not unknown knobs.

## TONE3000 has thousands of capture packs and a no-bulk rule

| Question | Answer |
|---|---|
| How many? | **About 10,200 packs** (10,197 [sitemap](https://www.tone3000.com/sitemap.xml) entries, one a duplicate) and "100K models" by July 2025 ([changelog](https://www.tone3000.com/changelog)). Amp packs of every kind are roughly 4,000–5,000, a rough estimate from pack names; `amp-cab` packs were not counted. A real count needs TONE3000 (ask in the access request) or the API's gear filter once allowed. Total size is not published. |
| Licence? | **Per pack**, the creator's choice: T3K, CC variants or CC0 ([API](https://www.tone3000.com/api)). T3K lets users "use the data file in software and publish the resulting outputs" but not redistribute it ([example](https://www.tone3000.com/tones/laney-irt-studio-39500)). T3K is not one of the rule's named categories; this report reads it as fitting (free, allows use and publishing outputs). |
| Mic and cab? | Amp Head is "Amplifier only"; Amp + Cab is "Mic'd combo amp or amp head with cabinet" ([guide](https://www.tone3000.com/guides/capture-your-gear-with-nam-sweep-method)). The tag is the creator's. The sampled `amp-cab` pack, Laney IRT Studio, is a GuitarML Proteus pack "captured through the built-in cabinet emulation" ([page](https://www.tone3000.com/tones/laney-irt-studio-39500)); a NAM `amp-cab` pack listed on the same page, "Modified 5E3 Tweed Deluxe Clone", names an AT-2020. The sharing rules ban only commercial IRs "used as the cab in your capture" ([policy](https://www.tone3000.com/guides/tone-sharing-guidelines)). |
| IRs paired? | Usually not: each pack has an IR count (0 on both packs sampled), and how often amp-head packs include IRs is unknown ([API](https://www.tone3000.com/api)). |
| Bulk access? | **Forbidden** by the site [Terms](https://www.tone3000.com/terms) ("a substantial portion of available tones for any purpose") and the [API Terms](https://www.tone3000.com/api/terms) ("Do not bulk download, scrape, mirror, or cache"). |
| Capture audio shared? | **Not by TONE3000**: its licence from creators is "limited to internal purposes" ([Terms](https://www.tone3000.com/terms)). No public archive of capture input/output files was found. |

**Only `amp-cab` packs can be real mic'd chains:** filter to NAM packs whose description names a mic. An amp-head capture plus a cab IR the project picks is not one. Captures are close copies: after the A2 retrain the library's median error-to-signal ratio is 0.0033 ([A2 guide](https://www.tone3000.com/guides/nam-a2-the-complete-guide)). Unknown knob settings do not matter, because labels come from the search. Input level does. A `.nam` file can store its expected input level ([NAM docs](https://neural-amp-modeler.readthedocs.io/en/latest/model-file.html)), but the one NAM pack sampled had no calibration ([Bad Cat](https://www.tone3000.com/tones/bad-cat-jet-black-106905)); the other sampled pack is Proteus. Smaller catches: "Convert" models are rebuilt from older models ([A2 guide](https://www.tone3000.com/guides/nam-a2-the-complete-guide)), some old uploads capture software ([example](https://tone3000.com/tones/mesa-mark-ii-c-from-proteus-software-2173)), and paid tones are "coming soon" ([policy](https://www.tone3000.com/guides/tone-sharing-guidelines)).

The plan's line "Bulk-download NAM captures | TONE3000's terms forbid it" still holds. Suggested wording: **"Bulk, scripted or scraped download or caching of TONE3000 captures | Forbidden by TONE3000's site Terms (2025-03-12) and API Terms (2026-07-07). Each pack's licence (T3K in both packs sampled) allows using it and publishing renders, so the only routes are access TONE3000 grants on request, or hand downloads within limits the user has checked."** The user decides between emailing support@tone3000.com for research access (cleanest), picking 100–300 packs by hand (the Terms never define "normal human browsing patterns"), or fetching favourites through the free API (possibly the forbidden "cache"). The last two need an account, and so would downloading after access is granted.

Other capture libraries are smaller or blocked. GuitarML has 59 amp captures, per Open-Amp ([arXiv](https://arxiv.org/html/2411.14972v1)), mostly with no cab; its licence is unclear, so the user checks ([library](https://guitarml.com/tonelibrary/tonelib-pro.html)). IK's ToneNET offers 60,000+ captures through the free TONEX 2 CS plug-in, in a closed format, under terms that could not be fully read ([terms](https://www.ikmultimedia.com/legal/terms_and_conditions_template_txc_us.php)): the user checks. IK says "Over 60,000 free Tone Models" ([IK](https://www.ikmultimedia.com/products/tonex2/)); SonicState says "more than 60,000 free and premium" ([SonicState](https://sonicstate.com/news/2026/10/23/ik-multimedia-releases-tonex-free-unlimited/)). GitHub re-hosts carry licences picked by the re-hoster ([example](https://github.com/troutstar/NAM_models)): the user checks. Kemper and Quad Cortex need their paid hardware ([Kemper](https://www.kemper-amps.com/rig-manager)), so they are out under the rule.

## GOAT joins captures to real cab IRs at random

GOAT renders **5.9 h of DI covers through captures drawn from about 7,000 NAM profiles of over 1,000 amps** ([paper](https://arxiv.org/html/2509.22655v1)). It is CC BY-NC 4.0, restricted and research only ([Zenodo](https://zenodo.org/records/15690894)), and the user requested access on 2026-10-23. The paper gives each item a random profile and a random Nolly mic, and "This process was repeated 5 times over, resulting in 29.5 hours": about 172 × 5 ≈ 860 draws, so several hundred distinct captures (estimate). For T3K profiles, "publish the resulting outputs" supports sharing those renders.

Its cabs are IRs "from the NeuralDSP Archetype Nolly plugin" (paper), which Neural DSP describes as "hundreds of impulse responses captured by Nolly using his favorite microphones" ([Neural DSP](https://neuraldsp.com/plugins/archetype-nolly)). So the cab and mic are real recordings, but each render joins a random cab IR to a capture of a different amp, so **no render is one real rig**. Archetype Nolly is not one of the project's targets ([README](../../README.md)). The paper does not say how the profiles were collected, how hot the DI was driven, or whether `amp-cab` profiles also got a cab IR; if they did, those renders have two cabs.

The size was checked on 2026-11-01. Zenodo lists 8.5 TB as "Total data volume" beside 283 unique downloads (732 downloads in all, in its statistics). So it is the **sum of all downloads**, not the archive; the average, about 11.6 GB a download, may be a single file. The real size is unknown, and the earlier 15–25 GB guess is unverified ([DI source inventory](di-source-inventory-2026-10.md)). The project keeps a 31 GB free-space guard ([fix plan](../pipeline-fix-plan.md)), so the size matters. The file list is hidden, so whether a part can be fetched shows only once access is granted.

## Free IRs and shootouts add cabs, not chains

Free IR libraries cover about 10–20 real cabs. God's Cab has one Mesa 4x12 ([Rekkerd](https://rekkerd.org/signals-audio-releases-gods-cab-1-3-free-ir-library)), Redwirez has one Marshall 1960A with 17 mics ([Rekkerd](https://rekkerd.org/?p=25023)), and Origin has 6 cabs ([SOS](https://www.soundonsound.com/news/origin-effects-launch-free-ir-cab-library)). Celestion's licence bans derivative works ([quote](https://forum.kemper-amps.com/forum/thread/42300-poll-ethics-of-profiling-using-impulse-responses/?pageNo=4)) and Kalthallen's could not be read ([page](https://shop.kalthallen.de/?page_id=423)), so the user checks both. An IR joined to an amp the project picks is not a real mic'd chain. Forum shootouts re-amp one DI through 3–12 amps ([Rig-Talk](https://www.rig-talk.com/forum/threads/high-gain-amp-shootout.178021)), but they are lossy, unlicensed and rarely include the DI: spot checks only.

## Conclusion

Real recordings at this scale do not exist publicly, so the choice is how much realism to give up. Filtered `amp-cab` captures keep the real amp, cab and mic but fix one setting and hide the input level; GOAT joins each capture to a random real cab IR. The cheap check is whether a centre learned from capture renders improves the leave-one-out score on the 14 BKS recordings. If too few packs are calibrated, fix the input level by a declared rule rather than letting the search pick it: a search-picked level pulls the centre toward sounds the plugin can already reach.
